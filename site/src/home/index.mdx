## Quick start

```bash
git clone https://github.com/lucdoe/opengateway.git
cd opengateway
go run ./cmd/opengateway
```

Or `docker compose up --build`, which also starts Redis. Then describe your services in `cmd/opengateway/config.yaml`:

```yaml
Services:
  starwars:
    URL: "https://swapi.dev"
    Subpath: "/api"
    Plugins: ["logger", "rate-limit"]
    Endpoints:
      - HTTPMethod: "GET"
        Path: "/people/{id}"
        Plugins: ["cache"]
```

`GET /api/people/7` on port 4000 is forwarded to `https://swapi.dev/api/people/7`.

## Fast

With every plugin on and two CPU cores: **16,000 requests/s**, **+0.3 ms** median added latency, cache hits in **0.13 ms**. See the [benchmark](https://github.com/lucdoe/opengateway#performance).
